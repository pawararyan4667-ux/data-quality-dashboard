# Data Quality Dashboard

## Overview
This project is a DAMA-aligned Data Quality Dashboard built using Python, Pandas, Streamlit, and Plotly.

The dashboard evaluates dataset health using key Data Quality dimensions:
- Completeness
- Accuracy
- Consistency

The project was developed as part of an internship focused on Data Quality, Data Governance, and AI Governance.

---

## Features

- Missing value analysis
- Duplicate detection
- Invalid data detection
- Data Quality scoring
- Interactive dashboard
- Business insights reporting

---

## Technologies Used

- Python
- Pandas
- NumPy
- Streamlit
- Plotly
- Seaborn
- Matplotlib

---

## DAMA Data Quality Dimensions Implemented

| Dimension | Implementation |
|---|---|
| Completeness | Missing value analysis |
| Accuracy | Invalid age/fare validation |
| Consistency | Duplicate detection |
